How to use this application

  1. Paste instructor-approved practice questions in the Import Questions section.
  2. Use the supported JSON format so every question includes a domain, answer, explanation, and misconception.
  3. The app automatically distributes questions across 10 progressively integrated sessions.
  4. Students practice with quiz and flashcard modes, then review the mastery report.
Content safeguard: The uploaded prompt explicitly says to wait for the practice-test content. Therefore, this version includes the full learning engine but no fabricated ITT101 questions.

Mastery standard

A domain is considered mastered at 80% or higher across answered questions. Scores below 70% are flagged for immediate remediation. Later sessions blend multiple domains to reduce memorization and improve transfer.

Required question structure

[
  {
    "session": 1,
    "domain": "Hardware Components",
    "format": "multiple-choice",
    "difficulty": "foundation",
    "prompt": "Instructor-provided question or scenario",
    "choices": ["Choice A", "Choice B", "Choice C", "Choice D"],
    "answer": 1,
    "explanation": "Why the correct answer is correct.",
    "misconception": "Why a common wrong answer seems attractive.",
    "mnemonic": "Optional memory aid"
  }
]

answer uses a zero-based choice number: 0 = first choice, 1 = second choice. Session may be 1–10. If omitted, the app assigns a session based on difficulty and domain rotation.
