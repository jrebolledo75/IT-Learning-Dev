Definition

What is IT?

Information technology can describe computer systems and their components, the staff who maintain them, and careers focused on creating, connecting, configuring, troubleshooting, programming, and securing technology.

Digital World

Hardware + Software + Protocols + Users

Modern digital systems combine physical devices, programs, communication rules, and people or organizations.

Computer System

Minimum Requirements

A computer needs a processor to execute instructions and memory to hold working instructions and data. Input, output, storage, and networking extend the system.

Computer Types

From Smartphones to Supercomputers

Computers differ in size, cost, processing capability, memory, storage, and purpose. General-purpose systems run many programs; special-purpose systems focus on narrower tasks.

Programming

High-Level to Machine Code

A compiler can translate one high-level instruction into several machine instructions. Assembly instructions generally map more directly to machine instructions.

Memory Hierarchy

Registers, Cache, RAM, Storage

Registers are inside the CPU. Cache keeps recently used instructions and data close to the processor. Main memory is on the motherboard. Storage saves files long term.

Networks

Input and Output

A network sends and receives data. In the IPOS model, network communication can act as both input and output.

IT Skills

Troubleshooting + Soft Skills

Technical skills include system, software, hardware, network, and security troubleshooting. Communication, teamwork, listening, and independent learning are essential professional skills.

Reflection

Tech Around Me

Identify three technologies you used today and explain the hardware, software, network, and people involved.

Digital Divide

Access Is Not Equal

The digital divide can result from economic, demographic, political, geographic, educational, physical, and accessibility factors. It includes differences in devices, broadband access, and digital literacy.

Algorithm Awareness

Understand Recommendations

Search results and product recommendations are ordered by algorithms. A digitally literate user evaluates why information appears and does not assume the first result is automatically the best.

Accessibility

WCAG Principles

Accessible websites should be perceivable, operable, understandable, and robust. Images need descriptive alt text, navigation should work by keyboard, and page structure should remain consistent.

Health

Ergonomics and Breaks

Computer use can contribute to carpal tunnel syndrome, computer vision syndrome, musculoskeletal disorders, headaches, reduced focus, and sleep problems. Proper posture and regular breaks reduce risk.

E-Waste

Technology Has a Physical Cost

Discarded electronics contain potentially harmful materials. Responsible reuse, secure data wiping, donation, and approved recycling help reduce environmental and health impacts.

Online Threats

Scams, Bullying, and Deepfakes

Digital citizens should recognize typosquatting, fraudulent messages, cyberbullying, fake or misleading content, and media generated or manipulated with AI.

Software Failure

Small Errors, Large Consequences

Y2K, the Ariane 5 failure, Apollo guidance overloads, and faulty software updates demonstrate why testing, risk analysis, fallback plans, and responsible deployment matter.
