# NCC IT Learning Hub Professional Edition

Current production build: **v1.1.1**

Open `index.html`, then select **ITT103 > Week 1 > Mission Ready** to test the Business Software Consultant activity.


## Start here
1. Extract the ZIP file.
2. Open `index.html` in Chrome or Microsoft Edge.
3. On the ITT102 course card, click **Launch Week 1** for direct access, or **Open Weekly Reviews** to view the ITT102 weekly pathway.

Week 1 includes concept lessons, motherboard matching, rear-panel identification, storage-device identification, and the Chapter 2 quiz. Progress is stored locally in the browser.
