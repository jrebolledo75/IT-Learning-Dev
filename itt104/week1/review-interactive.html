Chapter 8: Must-Know Review

Big idea: Programming languages let people express algorithms at different levels of abstraction. Translators convert source code into forms a computer can execute, and programming paradigms organize how developers structure solutions.

1. Language levels

  • Machine language: binary/hexadecimal instructions native to a processor.
  • Assembly: mnemonics with nearly one-to-one mapping to machine instructions.
  • High-level: human-readable constructs such as assignments, selections, loops, and subroutines.

2. Translators

  • Assembler: assembly → machine code.
  • Compiler: translates the whole high-level program before execution.
  • Interpreter: translates and executes instructions as the program runs.
  • JIT/runtime: source → bytecode/intermediate code → virtual machine execution.

3. Errors & debugging

  • Syntax: violates language rules; often found during compilation.
  • Run-time: occurs during execution, such as divide-by-zero or file-not-found.
  • Logical: runs but produces an incorrect result.
  • Debugging: locating and correcting errors.

4. Data & control

  • Variables have a name, type, value, and scope.
  • Arrays are homogeneous; records may contain mixed field types.
  • Selection chooses a path; iteration repeats instructions.
  • An infinite loop occurs when its terminating condition never becomes false.

5. Language history

  • FORTRAN: scientific/math; early reliance on GO TO.
  • COBOL: business data, English-like syntax, records.
  • LISP: AI, recursion, lists, prefix notation, interpreted.
  • ALGOL: blocks and recursion; influenced C and Pascal.
  • Ada: US government standardization effort, strong typing.

6. Paradigms

  • Structured: control structures replace excessive GO TO.
  • Modular/procedural: programs divided into subroutines.
  • OOP: classes, objects, encapsulation, inheritance, polymorphism, message passing.
  • Functional: computation emphasized through functions (for example, LISP).

Quiz-focused facts

  • COBOL input keyword: ACCEPT.
  • COBOL variables are declared in the data definition section.
  • COBOL conditional loop: PERFORM … UNTIL.
  • FORTRAN used = for both assignment and equality in the historical framing used by the quiz.
  • Perl scalar and array prefixes: $ and @.
  • Java compiles into bytecode; the JVM is a virtual machine.
  • LISP uses prefix notation and was an early interpreted language.
  • Code dominated by GO TO statements is called spaghetti code.
  • A linked list typically uses a pointer to connect nodes.
