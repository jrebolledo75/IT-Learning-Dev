Programming

Programming is the process of creating instructions that tell a computer how to perform specific tasks.

Programming Languages

  • Machine Language
  • Assembly Language
  • High-Level Languages

Translators

Object-Oriented Programming

⭐ Key Vocabulary

Program – Set of instructions.

Algorithm – Step-by-step solution.

Compiler – Converts an entire program.

Interpreter – Executes one statement at a time.

Machine Language – Binary instructions.

Assembly Language – Low-level language.

High-Level Language – Easier for programmers.

Syntax Error – Violates language rules.

Run-Time Error – Happens while running.

Logical Error – Produces incorrect results.
