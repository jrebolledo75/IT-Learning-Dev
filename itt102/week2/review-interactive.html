📖 Week 2 Study Guide

Network foundations

IP address: identifies a device/interface on an IP network.

DNS: translates human-friendly names into IP addresses.

Router: connects networks and forwards traffic.

Wi-Fi: provides wireless network access; Wi-Fi connection alone does not prove Internet access.

Protocols & ports

HTTP 80 • HTTPS 443 • SSH 22 • DNS 53 • SMTP 25 • IMAP 143 • DHCP 67/68.

Connect each port to the service purpose and a troubleshooting situation—not just the number.

Cabling & topology

Copper Ethernet uses twisted-pair cable and RJ45 connectors. Correct conductor order, seating, jacket placement, crimp quality, and tester results matter.

Topology choices affect cost, redundancy, growth, and troubleshooting.

Cloud & virtualization

Compare local, cloud, VM, container, edge, serverless, hybrid and multi-cloud choices using security, cost, scalability, performance, administration and recovery.

Subnetting

Subnetting divides a larger IP network into smaller logical networks. Week 2 practice divides 192.168.0.0/24 into four /26 departmental networks.

Customer communication

Think like a support technician: explain accurately in plain language, ask focused questions, gather evidence, and avoid overwhelming the user with jargon.
